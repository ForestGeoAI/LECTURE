이 가이드 보는 법

1. 노트북 화면을 반으로 나눕니다. 왼쪽에는 앱, 오른쪽에는 이 가이드를 띄웁니다.

1

앱 창을 한 번 누릅니다.

2

키보드에서 윈도우 키 + ← 를 누릅니다. 앱이 화면 왼쪽 절반으로 갑니다.

3

이 가이드 창을 한 번 누릅니다.

4

윈도우 키 + → 를 누릅니다. 가이드가 오른쪽 절반으로 갑니다.

(맥: 창 왼쪽 위 초록 단추에 마우스를 올리면 나오는 메뉴에서 왼쪽 · 오른쪽을 고릅니다)

2. 검은 상자의 문장은 복사 단추로 복사해 앱 입력창에 붙여 넣고 Enter 를 누릅니다. 직접 치면 글자가 달라져 결과가 달라질 수 있습니다.

3. 초록 상자가 「이렇게 보이면 성공」, 빨간 상자가 「막히면」 입니다. 빨간 상자의 문장을 그대로 다시 말하면 대부분 풀립니다.

4. 위 「내가 쓰는 앱」에서 앱을 고르면 폴더 · 권한 · 모델 설명이 그 앱 기준으로 바뀝니다. 문장은 어느 앱이든 같습니다.

준비에이전트를 내 컴퓨터에 들이기

15분 · 앱을 열고 단추 세 개 — 폴더 · 권한 · 모델 — 을 맞춘 뒤 인사합니다. 집에서 미리 해 오면 수업에서는 0-6 인사부터 시작합니다.

0-1자료 풀고 앱 열기

1

실습 자료 zip 을 C:\workspace 에 풉니다. (맥: 홈 폴더 아래 workspace)

풀고 나면 실습01 · 실습02 · 실습03 폴더와 따라할_문장.txt 가 보여야 합니다. 폴더 이름은 바꾸지 마세요 — 문장이 이 이름을 그대로 씁니다.

2

앱을 열고 평소 쓰는 계정으로 로그인합니다.

3

일하는 화면으로 들어갑니다.

Antigravity
  1. antigravity.google 에서 내려받아 설치합니다. 구글(Gemini) 기반 에이전트 앱으로, 무료 사용량이 있고 사용량은 구글 계정 단위입니다.
  2. 구글 계정으로 로그인합니다. 개인 계정을 권장합니다.
  3. 첫 화면에 Projects 가 보이면 들어온 것입니다.
클로드
  1. claude.ai/download 에서 Claude 데스크톱 앱(Windows · Mac)을 설치하고 로그인합니다.
  2. 왼쪽 메뉴에서 Cowork 를 고릅니다. 내 PC 의 폴더를 다루는 Cowork 는 유료 요금제(Pro 이상)에서 쓸 수 있습니다. 무료 계정이면 오늘은 Antigravity 로 하세요.
  3. 터미널에 익숙하면 Claude Code(명령창에서 claude)로 같은 문장을 써도 됩니다.
ChatGPT (Codex)
  1. ChatGPT 의 에이전트 앱은 Codex 입니다. Windows 는 Microsoft Store 에서 「Codex」를, Mac 은 chatgpt.com/codex 에서 내려받아 설치합니다.
  2. ChatGPT 계정으로 로그인합니다. 사용량은 요금제에 따라 다르며 유료 구독(Plus 등)을 권장합니다.
  3. Windows 사용자 이름이 한글이면 첫 실행에서 오류가 날 수 있습니다 → 영문 이름의 Windows 계정을 쓰거나, 환경 변수 CODEX_HOME 을 C:\codex 같은 영문 폴더로 지정합니다. 안 되면 오늘은 Antigravity 로.
이렇게 보이면 성공앱 첫 화면이 떠 있고, 탐색기에 C:\workspace\실습01 폴더(엑셀 4개)가 보입니다.

처음엔 복잡해 보여도 세 군데만 알면 됩니다.

1

왼쪽 — 프로젝트(폴더)와 지금까지 나눈 대화 목록입니다. 새 대화는 여기서 엽니다.

2

가운데 — 에이전트와 주고받는 말이 나옵니다. 에이전트가 어떤 파일을 읽고 만들었는지도 여기 나옵니다.

3

입력창 근처 — 설정 단추들이 있습니다. 오늘은 이 가운데 세 개만 맞춥니다: 폴더 · 권한 · 모델.

Antigravity

오른쪽에 하나 더 — 보조 창(Auxiliary Pane). 오른쪽 위 단추로 여닫으며, 에이전트가 세운 Task list 와 Implementation Plan, 끝난 뒤 Walkthrough(결과 요약)가 여기 뜹니다.

클로드

Cowork 에서는 작업 중에 할 일 목록이 가운데에 보이고, 끝나면 만든 파일이 카드로 나타납니다. 연결한 폴더는 입력창 위에 이름으로 표시됩니다.

ChatGPT (Codex)

왼쪽에 프로젝트 목록, 가운데에 대화, 입력창 아래에 권한 단추와 모델 단추가 있습니다. 바뀐 파일은 차이(diff)로 보여 줍니다.

0-3폴더 — 에이전트의 책상

에이전트는 받은 폴더 안에서만 일합니다. 그래서 이 폴더를 에이전트의 책상이라고 부릅니다. 오늘은 모두 같은 자리 — C:\workspace\실습01 (맥: ~/workspace/실습01). 폴더는 zip 을 푼 자리에 이미 있으니 고르기만 하면 됩니다.

Antigravity
  1. 왼쪽 Projects → Create New Project (또는 New Project)
  2. Add Folder → C:\workspace\실습01 고르기 → Create
  3. Start first conversation 을 눌러 대화를 엽니다

workspace 전체를 고르지 않습니다 — 실습 폴더 하나씩. 책상이 좁을수록 에이전트가 헤매지 않고 사용량도 아낍니다. 실습 2 · 3 은 같은 방법으로 새 프로젝트를 만듭니다.

클로드
  1. + 새로 생성 → 입력창 위 폴더 이름 단추
  2. → 폴더 열기… → workspace → 「실습01」 고르기 → 폴더 선택

폴더 + 모양 단추(다른 폴더 추가)는 누르지 않습니다. 연결한 폴더 안의 파일만 읽고 쓸 수 있습니다.

ChatGPT (Codex)
  1. 프로젝트 + → 이름 「실습01」 → 소스 폴더 추가
  2. → workspace 안 「실습01」 고르기 → 프로젝트 만들기 → Trust folder → 연필(새 대화)

폴더 선택창이 바탕화면에서 열리면 C 드라이브로 올라가 workspace 를 찾습니다.

이렇게 보이면 성공왼쪽 목록에 「실습01」, 가운데에 빈 입력창.

0-4권한 — 물어볼지, 알아서 할지

에이전트는 폴더 안에서 파일을 읽고, 쓰고, 프로그램을 실행합니다. 권한은 이걸 할 때마다 나한테 물어볼지, 알아서 할지 정하는 단추입니다. 물어보게 하면 안전하지만 허락을 계속 눌러야 하고, 알아서 하게 두면 끝까지 쭉 일합니다.

Antigravity
  1. 왼쪽 프로젝트 이름 옆 톱니(⚙) → Project settings
  2. Security Preset — 터미널 명령 · 파일 접근을 검토 없이 진행하는 쪽으로
  3. Agent Behaviour — 계획(Plan)은 검토 없이 바로 실행으로

IDE 형태로 쓰는 분은 Settings → Agent → Terminal Command Auto Execution: Always Proceed · Review Policy: Always Proceed 가 같은 뜻입니다. 프로젝트마다 따로 설정되니 실습 2 · 3 에서 다시 확인합니다.

클로드
  1. 설정 → Claude Code → 권한 우회 모드 허용 켜기
  2. 입력창 아래 권한 단추(처음엔 「편집 자동 수락」) → 권한 무시

Cowork 에서 승인 창이 뜨면 무엇을 하려는지 한 줄 읽고 허용합니다. 기관 계정이라 스위치가 없으면 그대로 두고, 허락 창이 뜰 때마다 읽고 누르면 됩니다.

ChatGPT (Codex)
  1. 설정(Ctrl + ,) → 일반 → 전체 액세스 켜기
  2. 앱으로 돌아가기 → 권한 단추 → 전체 권한
약속「알아서」는 오늘 만든 실습 폴더에서만 씁니다. 내 문서 폴더처럼 중요한 파일이 든 곳에서는 「물어보기」로 둡니다. 개인정보 · 공개하면 안 되는 자료는 넣지 않습니다.
이렇게 보이면 성공실습 중 「허락해 주세요」 창이 거의 뜨지 않습니다.

막히면

막히는 곳은 대부분 비슷하고, 대부분은 에이전트에게 다시 말하면 풀립니다.

이럴 때이렇게
다른 폴더 이름이 나와요새 대화를 열고 실습 폴더를 다시 고릅니다 (0-3)
「허락해 주세요」 창이 계속 떠요권한이 「물어보기」입니다 → 0-4 를 다시 봅니다
파이썬 · 패키지가 없대요「필요한 프로그램이나 패키지는 네가 설치하고 다시 해 줘」
설치가 몇 분째예요공간 패키지(rasterio · geopandas)는 처음 설치에 3~5분 — 기다립니다 · 10분 넘으면 「설치를 멈추고 지금 있는 걸로 해 줘」
엑셀 파일을 못 고친대요그 파일을 열어 둔 엑셀 창을 닫고 다시 보냅니다
게임 화면이 하얗게만 나와요「화면이 안 보여. 고쳐 줘」 → 고친 뒤 브라우저 F5
지도 그림이 안 열려요PNG 가 아닌 형식으로 저장됐는지 봅니다 → 「지도를 PNG 그림으로 다시 저장해 줘」
한글이 깨져요「엑셀에서 열어도 한글이 안 깨지게 다시 저장해 줘」
그럴듯한 숫자를 지어냈어요조건을 겁니다 — 「비어 있던 값은 지어내지 말고 「확인 필요」라고 적어 줘」
결과가 이상해요어디가 이상한지 한 줄로 — 「2조 본수가 원본보다 적어. 다시 확인해 줘」
